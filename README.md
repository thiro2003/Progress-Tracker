# Social Media Portfolio

A responsive single-page portfolio website built using HTML, CSS, and JavaScript in one HTML file.

## Features

- Responsive design for desktop, tablet, and mobile
- Social media profile links:
  - LinkedIn
  - LeetCode
  - HackerRank
  - Naukri
  - Gmail
- Copy Link button for every profile
- Visit button for opening profiles in a new tab
- LeetCode solved-question counter
- HackerRank solved-question counter
- Increase, decrease, and reset counter buttons
- Total questions solved display
- Progress bar based on total questions solved
- Counter values stored using `sessionStorage`
- Toast notifications
- No external libraries required
